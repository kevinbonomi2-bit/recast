# Building Recast

## Run from source

Needs Python 3.12 or newer on Windows.

```
"Start Recast.bat"
```

The first run creates `.venv` and installs `requirements.txt`. Or by hand:

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m recast
```

## Tests

```
.venv\Scripts\python -m pytest tests
```

Media tests need FFmpeg on PATH. A few tests start the helper process and take a couple of seconds.

## Command line

```
.venv\Scripts\python -m recast ops photo.jpg                 # what each wheel offers
.venv\Scripts\python -m recast run image.to.webp photo.jpg   # run one operation
.venv\Scripts\python -m recast wheel photo.jpg               # open the wheel for a file
```

## The packaged app and installer

```
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

This regenerates the logo files in `brand\`, builds `dist\Recast\Recast.exe` with PyInstaller (a standalone folder, no Python needed) and, if [Inno Setup 6](https://jrsoftware.org/isinfo.php) is installed, `dist\Recast-Setup-<version>.exe`. The installer works per user without an admin prompt.

Close any running `dist\Recast\Recast.exe` first: Windows locks the folder while it runs.

## Layout

| Path | What's there |
| --- | --- |
| `recast/engine/` | Conversions. Each tile is an `Operation` registered with `@op(...)` |
| `recast/engine/lazy.py` | Heavy libraries, imported on first use |
| `recast/helper.py` | The short-lived helper process for PDF, HDR, documents and Trim |
| `recast/win/hooks.py` | Global mouse and keyboard hooks that detect a key tap during a drag |
| `recast/win/watch.py` | Folder watching for Clip Inbox, Recycle Bin, foreground checks |
| `recast/ui/wheel.py` | The wheel |
| `recast/ui/` | Cards, tool windows, Settings, theme, logo |
| `recast/estimate.py` | Size estimates shown on tiles, from file headers only |
| `recast/app.py` | The tray app that ties it together |
| `brand/` | Logo masters and the icon, generated by `brand/build_brand.py` |
| `packaging/` | PyInstaller and Inno Setup scripts |

## Adding a conversion

Add a function to the right module in `recast/engine/` and register it:

```python
@op("image.compress", "Compress", "tools", IMG, hint="Smaller file, same format")
def compress(src: Path, ctx: Context) -> list[Path]:
    ...
    return [output_path]
```

Use `output_for(src, ext, tag)` for the output path so nothing is ever overwritten, call `ctx.progress(fraction)` on long work, and add a case to `tests/test_engine.py`. If it needs a library that costs real memory, import it inside the function and list the module in `recast/helper.py` so it runs in the helper process.

## Memory rules

Recast sits in the tray all day, so the tray process stays small (about 30 MB):

- Don't import a heavy library at module level. `tests/test_helper.py` fails if the tray process loads one.
- Work that needs one runs in the helper process and exits.
